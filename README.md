# Amazon Sales & Reviews Analysis in Power BI

This project uses **Power BI Desktop** and **Excel** to explore and analyze Amazon's product sales and customer reviews. The goal is to track performance metrics like YTD sales, product movement, and customer feedback — and draw actionable insights through interactive visualizations.

---

## Dashboard Demo

![Dashboard Demo](./images/Dashboard_Demo.gif)

---

## Key Features

📌 **High-Level Insights**: Yearly and quarterly performance metrics  
📌 **Product Category Analysis**: Compare top-performing categories  
📌 **Review-driven Performance**: Drill into customer satisfaction  
📌 **Advanced DAX Measures**: For complex KPIs like YTD/QTD sales  
📌 **Visually Appealing**: Custom visuals, heat maps, and slicers

- **Power BI Desktop** for data modeling, DAX, and dashboard design
- **Excel (CSV/XLSX)** for data import and preprocessing

## Business Requirement

To perform an end-to-end analysis of Amazon product sales and customer reviews, using KPIs like YTD sales, product performance, and review counts to uncover trends and growth opportunities.

---

## KPI Requirements

| KPI Name              | Description                                      |
| --------------------- | ------------------------------------------------ |
| **YTD Sales**         | Total sales value from the beginning of the year |
| **QTD Sales**         | Total sales value from the current quarter       |
| **YTD Products Sold** | Total quantity sold across the year              |
| **YTD Reviews**       | Number of customer reviews received this year    |

## Dashboard Insights

### Highlights:

1. **Seasonality in Sales**: Strong Q2 spike driven by Prime Day and festive period
2. **Best Sellers**: Electronics & Home Appliances dominate revenue
3. **Customer Feedback**: Higher ratings correlate with faster-moving products
4. **Growth Opportunities**: Certain categories under review low-performing products

### Interactive Features:

- Multi-level drill-throughs
- Dynamic slicers for real-time filtering
- KPI indicator cards in the header

---

## 📂 How to Use

1. Download the `.pbix` file
2. Open in **Power BI Desktop** (version 2023+)
3. Refresh to view interactive dashboards
4. Explore insights with slicers and drill-throughs
